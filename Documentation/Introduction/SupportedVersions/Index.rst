==================
Supported versions
==================

The table lists the compatibility of all versions with TYPO3 and PHP and which
versions are still supported.

=====  =====  ====  ====================================
Books  TYPO3  PHP   Support/Development
=====  =====  ====  ====================================
2.x.x  14.2   8.2+  Features, Bugfixes, Security Updates
1.x.x  13.4   8.2+  Bugfixes, Security Updates
=====  =====  ====  ====================================

If you need extended support for features and bug fixes outside of the
currently supported versions, we are happy to offer paid services.

Security
========

Security updates are only provided for supported versions. Please do not report
security issues in public GitHub issues or pull requests. Report them to the
TYPO3 Security Team via security@typo3.org instead.
